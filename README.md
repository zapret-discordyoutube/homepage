## Что где лежит

| Файл | Зачем |
| --- | --- |
| `templates/home.tmpl` | разметка главной страницы: шапка, каталог проектов, баннеры, секции про сборки и поддержку |
| `templates/custom/header.tmpl` | подключение стилей и иконок, вставляется в `<head>` каждой страницы |
| `public/assets/zapret-moe/home.css` | все стили главной: неоновая палитра, анимации, адаптив |
| `public/assets/zapret-moe/*.webp`, `*.jpg` | скриншоты приложений и эмблема сообщества |
| `public/assets/img/` | логотип и фавиконки всего сайта |

Пути внутри репозитория повторяют структуру каталога `custom/` у Forgejo — файл кладётся ровно туда, где лежит на сервере.

## Как предложить правку

1. Нажмите **Fork** и клонируйте свою копию.
2. Правьте файлы. Разметка — обычный HTML внутри Go-шаблона: конструкции в двойных фигурных скобках (`{{AppSubUrl}}`, `{{if .IsSigned}}`) трогать не нужно, они подставляют адрес сервера и состояние входа.
3. Проверьте результат локально — как это сделать, написано ниже.
4. Откройте pull request в `main` этого репозитория. После принятия правка попадает на сайт сама, в течение пары минут.

## Как посмотреть изменения до отправки

Полноценный предпросмотр требует своего Forgejo, но 95 % работы — это вёрстка и стили, и их видно и без него. Сохраните рядом с `home.tmpl` файл `preview.html`:

```html
<!doctype html>
<html lang="ru"><head><meta charset="utf-8">
<link rel="stylesheet" href="public/assets/zapret-moe/home.css">
</head><body style="background:#02060f">
<!-- сюда вставьте содержимое home.tmpl, заменив {{AppSubUrl}} на пустую строку,
     а блоки {{if .IsSigned}}…{{else}}…{{end}} — на любую одну из веток -->
</body></html>
```

Откройте его в браузере — увидите верстку и все анимации. Для проверки на телефоне сузьте окно: страница адаптируется на 980, 760 и 460 пикселях.

## Правила оформления

- **Только синяя неоновая палитра.** Цвета берутся из переменных в начале `home.css` (`--zpm-neon`, `--zpm-blu`, `--zpm-ink` и другие) — используйте их, а не новые значения.
- **Никаких внешних ресурсов.** Шрифты, скрипты и картинки со сторонних сайтов не подключаем: страница должна открываться у людей с заблокированным доступом к половине интернета. Всё лежит рядом, в этом репозитории.
- **Картинки — в WebP**, ширина 1200 пикселей, вес до ~100 КБ. Скриншоты интерфейсов лучше делать в тёмной теме.
- **Анимации на CSS**, без JavaScript.
- **Проверяйте на узком экране**: длинные слова и кнопки не должны ломать вёрстку.

## Как правка попадает на сайт

На сервере лежит клон этого репозитория. Раз в две минуты systemd-таймер делает `git pull`; если появились новые коммиты в `main`, файлы копируются в каталог `custom/` Forgejo. Изменения в CSS и картинках видны сразу, изменения в шаблонах — после автоматического перезапуска сервиса, который делает тот же скрипт.

Ничего запускать вручную не нужно: смёржили pull request — через пару минут смотрите результат на https://git.zapret.moe/.
