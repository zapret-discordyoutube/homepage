## Главное правило

**Этот репозиторий — единственный источник правды.** Каталоги `templates/` и `public/` выкладываются в `custom/` Forgejo целиком: всё, чего нет в git, при следующей выкладке удаляется. Править файлы прямо на сервере бесполезно — правка проживёт максимум до следующего коммита.

## Что где лежит

| Файл | Зачем |
| --- | --- |
| `templates/home.tmpl` | разметка главной: заставка-презентация, шапка, пульс, арсенал, инструменты, сборки, поддержка |
| `templates/custom/header.tmpl` | вставляется в `<head>` **каждой** страницы: фавиконки и `site.css` |
| `templates/custom/footer.tmpl` | полоса ссылок на вики внизу **каждой** страницы |
| `templates/user/auth/signup_inner.tmpl` | регистрация без почты |
| `public/assets/zapret-moe/home.css` | стили главной; подключается только из `home.tmpl`, на другие страницы не влияет |
| `public/assets/zapret-moe/home.js` | заставка, синтезированная музыка к ней (Web Audio, без файлов) и «Пульс разработки» |
| `public/assets/zapret-moe/site.css` | то немногое, что нужно на всех страницах |
| `public/assets/zapret-moe/fonts/` | Unbounded и Onest (OFL), кириллица и латиница |
| `public/assets/zapret-moe/chars/` | РКН-тян и Запрет-тян, нарезанные на слои для анимации: основа, кисти рук, пряди волос, контровой свет. Координаты слоёв — в системе 1600×900, их точки вращения прописаны в разметке ригов в `home.tmpl` |
| `public/assets/zapret-moe/shot-gui.webp` | скриншот Zapret 2 GUI — единственная картинка, которой нет в репозитории проекта |
| `public/assets/img/` | логотип и фавиконки всего сайта |
| `public/robots.txt` | правила для поисковиков |
| `deploy/zapret-homepage-sync.sh` | скрипт выкладки, который крутится на сервере |
| `deploy/zapret-homepage-stats.py` + `.service`/`.timer` | раз в полчаса считает коммиты, релизы и скачивания для «Пульса» и пишет `public/assets/zapret-moe-stats/stats.json` |
| `tools/preview.sh` | локальный предпросмотр в настоящем Forgejo |

## «Пульс разработки»

Статистику считает `deploy/zapret-homepage-stats.py` на сервере, а не браузер каждого посетителя:

- коммиты — прямо из git-репозиториев организаций `zapretdiscordyoutube`, `zapretkvn`, `zastogram` (зеркала пропускаются). В форках с чужой историей (Telegram, MTProxy) засчитываются только коммиты наших авторов — тех, кто коммитил в наши собственные репозитории; боты не считаются;
- релизы и скачивания — из базы Forgejo, только публичные репозитории;
- закрытые репозитории входят в общие группы, их названия наружу не попадают.

Файл `stats.json` не лежит в git: скрипт выкладки специально сохраняет каталог `zapret-moe-stats` при зеркалировании. Если файла нет, главная строит график по публичному heatmap API.

## Картинки проектов не копируются

Обложки берутся прямо из репозиториев проектов — ровно те файлы, что показаны в их README:

- ZaStoGram — `zastogram/ZaStoGram_desktop/media/branch/dev/docs/assets/zastogram-overview.webp`
- Magisk Zapret 2 — `zapretdiscordyoutube/magisk-zapret2/media/branch/main/docs/assets/zapret2-control-ui.webp`
- Zapret KVN — `zapretkvn/ZapretKVN-android/media/branch/main/docs/assets/zapret-kvn-android-overview.webp`
- эмблема сообщества — аватар организации, `/zapretdiscordyoutube.png`

Поменяли обложку в проекте — главная показывает новую сама. Если переименовываете файл или ветку в проекте, поправьте ссылку в `home.tmpl`.

## Как предложить правку

1. Нажмите **Fork** и клонируйте свою копию.
2. Правьте файлы. Разметка — HTML внутри Go-шаблона: конструкции в двойных фигурных скобках (`{{AppSubUrl}}`, `{{if .IsSigned}}`) подставляют адрес сервера и состояние входа, их не трогайте. `@ASSETS_VER@` в ссылках на CSS и JS сервер заменяет хешем файлов — тоже оставьте как есть.
3. Проверьте результат: `tools/preview.sh` скачает Forgejo той же версии, что на сервере, и поднимет главную на http://127.0.0.1:3999/. Шаблоны рендерятся по-настоящему, так что синтаксическая ошибка видна сразу.
4. Откройте pull request в `main`.

## Как правка попадает на сайт

В контейнере Forgejo раз в две минуты запускается `deploy/zapret-homepage-sync.sh`. Если в `main` новый коммит, он:

1. собирает `templates/` и `public/` из этого коммита во временный каталог и подставляет в `@ASSETS_VER@` хеш `home.css`, `home.js` и `site.css`. Поэтому правка CSS/JS меняет шаблоны и перезапускает Forgejo на пару секунд, а замена картинки — нет;
2. атомарно подменяет каталоги в `custom/`, прошлую версию откладывает для отката;
3. если изменились шаблоны — перезапускает Forgejo и проверяет, что главная и регистрация отвечают. Пока Forgejo остановлен ночным бэкапом, выкладка откладывается. Не отвечает — возвращает прошлую версию и больше не выкладывает этот коммит, пока в `main` не появится новый.

После правки файлов из `deploy/` их нужно вручную поставить в контейнер (`/usr/local/sbin/` для скриптов, `/etc/systemd/system/` для юнитов): скрипт выкладки себя не обновляет.

## Правила оформления

- **Палитра** — синий неон и фиолетовый из артов: переменные в начале `home.css` (`--cy`, `--blu`, `--vio`, `--red` для РКН).
- **Никаких внешних ресурсов.** Шрифты, скрипты и картинки со сторонних сайтов не подключаем: страница должна открываться у людей, которым заблокирована половина интернета.
- **Анимации — на CSS и SVG.** JavaScript только как улучшение: без него страница полностью работает, заставка просто не показывается.
- **Уважайте `prefers-reduced-motion`**: для таких пользователей заставки нет, движение выключено.
- **Проверяйте на узком экране** (390 px): горизонтальной прокрутки быть не должно.
